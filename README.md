# 我家 3D

用手機錄影重建的三層樓透天厝，可以在瀏覽器（含手機）裡：

- 🚶 **參觀**：第一人稱逛 1F～3F，開門、開燈、日夜切換
- 🛋 **改裝潢**：在 3D 中搬家具、換油漆／地板／壁紙
- 📐 **空間編輯**：平面圖修改房間尺寸、畫牆、欄杆、加門窗、新增樓層
- 🎮 **遊戲**
  - 🪳 清潔大作戰：掃把、藍白拖、水槍、殺蟲劑、吸塵器，打蟑螂王
  - 👻 驅鬼大師：艾草棒、聖水槍、符咒、八卦鏡、法鈴，關卡越來越難，最後對決鬼王
  - 🔨 拆家狂人：大鐵鎚、武士刀、電鋸、手榴彈、大砲、火箭筒、超級炸彈，可以拆光再復原

設計會存在瀏覽器裡，可從選單匯出 / 匯入 JSON。

本機執行：在資料夾內執行 `python3 -m http.server`，再打開 http://localhost:8000
